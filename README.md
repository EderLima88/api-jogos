# API Lista de Jogos

## Descrição do Projeto
API RESTful desenvolvida em Spring Boot. Com persistência em banco de dados alocado em memória RAM para testes rápidos(H2).

---

## Tecnologias Utilizadas

* **Java 21**
* **Spring Boot (v3.3.2)**
* **Spring Data JPA**
* **Spring Web**
* **Banco de Dados H2 (Em Memória)**
* **Apache Tomcat (Embutido)**
* **Maven**
